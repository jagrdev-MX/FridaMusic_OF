# Código de conducta de FridaMusic

## Compromiso

La comunidad de FridaMusic y Frida Labs busca mantener un espacio técnico abierto, respetuoso y útil para personas con distintos niveles de experiencia.

Participar en Issues, Pull Requests, Discussions u otros canales del proyecto implica aceptar estas normas.

## Comportamiento esperado

Se espera que las personas participantes:

- discutan ideas y código, no ataquen a otras personas;
- den feedback técnico específico y accionable;
- acepten correcciones y desacuerdos de buena fe;
- respeten diferentes niveles de experiencia;
- eviten spam, hostigamiento, amenazas o discriminación;
- no publiquen información privada de terceros;
- no utilicen el proyecto para distribuir malware, credenciales robadas o contenido ilegal;
- respeten licencias, autoría y atribuciones de terceros;
- mantengan los reportes de seguridad sensibles en canales privados.

Las críticas fuertes al código son válidas cuando se centran en hechos técnicos. Los insultos personales, provocaciones persistentes o intentos de intimidación no lo son.

## Conductas no aceptadas

No se toleran, entre otras:

- acoso o ataques personales;
- lenguaje discriminatorio dirigido a una persona o grupo;
- amenazas o incitación a violencia;
- publicación deliberada de datos personales;
- spam o autopromoción persistente no relacionada;
- sabotaje deliberado de Issues, PRs o automatizaciones;
- incorporación consciente de secretos, malware o código destinado a comprometer usuarios;
- abuso de canales de seguridad para acosar o extorsionar.

## Moderación

Los mantenedores pueden editar, ocultar, cerrar o eliminar contenido que incumpla estas normas, y limitar la participación de cuentas que mantengan conductas abusivas.

Las decisiones de moderación deben buscar proteger el proyecto y la comunidad, no castigar desacuerdos técnicos legítimos.

## Reportar una conducta problemática

Para problemas dentro de GitHub puedes utilizar las herramientas de reporte de la plataforma. Si el asunto incluye información sensible, evita publicarlo en un Issue abierto y contacta por un canal oficial de Frida Labs.

Los reportes de vulnerabilidades deben seguir `SECURITY.md`.

## Alcance

Este código de conducta aplica a los espacios oficiales del proyecto y a interacciones públicas realizadas en representación de FridaMusic o Frida Labs.

## Atribución

Este documento está inspirado en los principios del Contributor Covenant y adaptado al contexto de FridaMusic.
